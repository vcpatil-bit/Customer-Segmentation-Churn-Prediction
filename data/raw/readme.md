# Raw Dataset

The raw IBM Telco Customer Churn dataset is not included in this repository.

The dataset used for this project is the IBM Telco Customer Churn dataset, commonly available through IBM/Kaggle educational resources.

Dataset name:

`WA_FnUseC_TelcoCustomerChurn.csv`

The raw dataset was used for data cleaning, exploratory data analysis, customer segmentation, and churn prediction.

For reproducibility, obtain the dataset from its original source and place the CSV file in this folder before running the notebook.
